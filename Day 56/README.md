# 🌐 Personal Portfolio Website (Flask)

A responsive personal portfolio website built with **Flask**, HTML, and CSS. This project demonstrates how to serve static files, render HTML templates, and create a clean, multi-section portfolio page using Flask.

This project is part of **Day 56** of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

---

## ✨ Features

* Dynamic website powered by Flask
* HTML templates using Jinja
* Responsive portfolio layout
* Custom CSS styling
* Static assets (images, CSS)
* Clean project structure
* Easy to customize with your own information

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/day56-flask-portfolio.git
cd day56-flask-portfolio
```

### 2. Create a virtual environment (optional)

**macOS/Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install flask
```

or

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
