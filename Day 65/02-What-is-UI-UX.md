# Color Theory

## Overview

Color theory is the study of how colors interact with each other
and how they can be combined to create different visual effects.

---

## Color Wheel

The color wheel is a visual representation of the relationships
between different colors.

---

## Primary Colors

- Red
- Yellow
- Blue

Primary colors are colors that cannot be created by mixing other colors.

---

## Secondary Colors

Secondary colors are created by mixing two primary colors.

- Red + Yellow → Orange
- Yellow + Blue → Green
- Blue + Red → Purple

---

## Color Harmony

Color harmony describes combinations of colors that look visually
pleasing together.

### Complementary Colors

Two colors that are opposite each other on the color wheel.

Example:

- Blue + Orange
- Red + Green
- Yellow + Purple

### Analogous Colors

Colors that are next to each other on the color wheel.

Example:

- Blue + Blue-Green + Green

### Triadic Colors

Three colors that are evenly spaced around the color wheel.

Example:

- Red + Yellow + Blue

---

## Color Psychology

Different colors can communicate different feelings or associations.

| Color  | Common Association  |
| ------ | ------------------- |
| Red    | Energy, urgency     |
| Blue   | Trust, calm         |
| Green  | Nature, growth      |
| Yellow | Happiness, optimism |
| Purple | Luxury, creativity  |

---

## Web Design

When designing a website, color can be used to:

- Create visual hierarchy
- Draw attention to important elements
- Communicate branding
- Improve readability
- Create a specific mood
