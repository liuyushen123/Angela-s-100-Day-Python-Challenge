## 🚀 Running the Project

Create and activate a virtual environment (recommended):

```bash
python -m venv .venv
```

Install Flask:

```bash
pip install flask
```

Run the application:

```bash
python main.py
```

or

```bash
flask run
```

depending on the exercise.
